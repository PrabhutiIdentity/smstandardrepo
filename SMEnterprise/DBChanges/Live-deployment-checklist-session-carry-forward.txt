Business Rule Confirmation
--------------------------
- Old session balance may still display
- Old session collection must be blocked once carry-forward is mapped

Operational Rule
----------------
- Already manually-adjusted old branches/students: keep manual
- Newly promoted students: use auto carry-forward
- Branches where school does not want carry-forward:
  keep SBranchMaster.IsCarryForwardApplicable = 0

Rollback Caution
----------------
- Do not delete system carry-forward fee type
- Do not rename system carry-forward fee type manually
- Do not run auto carry-forward blindly on branches already using manual custom due rows
