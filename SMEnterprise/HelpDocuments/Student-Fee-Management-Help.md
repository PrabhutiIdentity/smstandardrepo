# Student Fee Management Help Document

This help document is for school staff who use `Student Section -> Manage Fee`.

## Main Menu Path

Open:

- `Student Section -> Manage Fee`

Screen name:

- `Students Fee Management`

## Module Purpose

This screen is used for:

- checking student fee due
- monthly fee collection
- previous due recovery
- late fee calculation review
- partial fee payment
- fee payment entry
- old payment history check

## Top Filters

At top of the screen, use these filters:

- `Month`
- `Session`
- `Class`
- `Section`
- search icon

After selecting filters, click search icon to load student fee list.

Suggested screenshot:
- top filter bar with `Month`, `Session`, `Class`, `Section`

## Student List Grid

Each row shows:

- `Photo`
- `SR.No.`
- `Student`
- `Quota`
- `Amount`
- `Status`
- `View Details`

### Student section details

Usually visible:

- student name
- student ID
- roll number
- fee mode
- class
- section

### Amount section

This area can show:

- `Fee Amount`
- `Previous Dues`
- `Late Fee Fine`
- `Fee Concession`
- `Paid Amount`
- `Net Amount`

### Status colors

- `Paid`: full amount already cleared
- `Partial`: some amount paid, some balance pending
- `Pending`: no payment or full due pending

## Main Action Buttons

### `Pay Now`

Use when:

- student has pending or partial due

Purpose:

- open fee detail area
- select months / fee types
- enter amount
- submit payment

### `Payments`

Use when:

- you want to check previous receipts or payment history of that student

## Fee Detail Area

After clicking `Pay Now`, fee detail section opens below student row.

This section normally includes:

- month slider / month selection
- fee type rows
- month-wise dues
- total amount
- total paid
- total remaining
- payment input area

## Payment Entry Fields

Bottom payment area usually contains:

- `Net Total Amount`
- `Amount Paid`
- `Payment Mode`
- `Fee Date`
- `Ref No.`
- `Remarks`
- `Collected By`

### How to fill

- `Amount Paid`: enter amount received now
- `Payment Mode`: choose cash / bank / online mode
- `Fee Date`: enter actual collection date
- `Ref No.`: enter receipt reference, bank reference, or transaction id
- `Remarks`: any note for office use
- `Collected By`: name of cashier or staff

## How To Collect Fee

1. Open `Student Section -> Manage Fee`.
2. Select month, session, class, and section.
3. Click search icon.
4. Find student row.
5. Click `Pay Now`.
6. Verify fee months and fee types.
7. Check total due amount.
8. Enter `Amount Paid`.
9. Select `Payment Mode`.
10. Fill `Fee Date`, `Ref No.`, and other fields.
11. Click `Submit`.
12. Confirm payment in confirmation popup if shown.

## Full Payment Case

If complete due amount is paid:

- student status becomes `Paid`
- due becomes zero
- receipt can be printed from payment history / receipt flow

## Partial Payment Case

If only some amount is received:

- enter only current received amount
- status may remain `Partial`
- remaining fee can be collected later

## Discount Request

If `Request Discount` option is available:

- use it only when school policy allows concession request
- fill correct details
- submit request for approval

Do not reduce amount manually without approval workflow.

## Payment Confirmation

Before final save, confirm:

- student ID
- student name
- payment date
- payment amount

This helps avoid saving payment in wrong student account.

## Payment History

Use `Payments` button to review:

- previous payment dates
- paid amount
- pending amount
- receipt records

This is useful before collecting balance from a student.

## Daily Fee Counter Workflow

Suggested daily flow:

1. Select current month and active session.
2. Filter class and section.
3. Collect fees row by row using `Pay Now`.
4. Check `Payments` before taking balance payment.
5. Verify status changes from `Pending` to `Partial` or `Paid`.

## Common Mistakes To Avoid

- do not enter more than payable amount
- do not skip `Payment Mode`
- do not leave `Ref No.` blank for bank or online payment
- do not save fee against wrong class/section filter
- always verify `Net Amount` before submit

## Quick Support Notes

If calculation looks wrong:

- recheck selected month
- confirm student row
- verify previous dues and late fee
- check old payments from `Payments`
- refresh class/section filter and search again
