1. Sales/Purchase Module

1.1 Purpose

This module is used for stock purchase, stock sale, stock allocation, balance payment collection, invoice printing, payment receipt printing, sales due monitoring, and sales reporting.

1.2 Menu Path

  • Sale/Purchase -> Transactions
  • Sale/Purchase -> New Transaction
  • Sale/Purchase -> Sales Due List Report
  • Sale/Purchase -> Sales Report

1.3 Main Working Areas

Screen Purpose Use
Transactions Show all stock transactions Filter date-wise, open transaction, print invoice, print payment receipt
New Transaction / Transaction Details Create or update sale/purchase/allocation Add products, receive payment, receive balance, view payment history
Sales Due List Report Show pending sale balances Quick follow-up for balance collection
Sales Report Show sales summary and receipt status Filter by date and product, print invoice and receipt

1.4 Screen Guide: Transactions

Area Description
Stock Type Select Purchase, Sale, or Allocate (No Sale).
Start Date / End Date Filter transaction records by date range.
View Open full transaction details page.
Invoice Print Open and print invoice preview.
Payment Receipt Print Open and print latest payment receipt.

Field Use

1.6 How to Create a Sale Entry

  1. Open Sale/Purchase -> New Transaction.
  2. Select Transaction Type = Sale.
  3. Select session, class, section, and student or employee.
  4. Add stock item details.
  5. Enter payment details.
  6. Click Save or Pay Now.

1.7 Full Payment and Partial Payment

Scenario System Result
Full Payment Due amount becomes zero, payment status becomes paid, invoice and receipt can be printed.
Partial Payment Due amount remains pending, payment status becomes partial, balance can be received later.

1.8 Balance Payment Process

  1. Open sale from Sales Due List Report, Sales Report, or Transactions.
  2. Check due amount.
  3. Enter current balance collection in This Time Payment Amount.
  4. Fill payment mode and reference number.
  5. Click Pay Now.

1.9 Payment History and Receipt Cancellation

Payment history shows receipt-wise entries.

Column Use
Receipt No System generated receipt number
Status Paid, Partial, or Cancelled
Cancel Date Date on which receipt was cancelled
Receipt Print receipt preview
Action Cancel latest active receipt only
Receipt cancellation must follow sequence. Only latest active receipt should be cancelled first. This keeps due amount and payment history correct.

2.8 How to Collect Fee

  1. Open Student Section -> Manage Fee.
  2. Select month, session, class, and section.
  3. Click search.
  4. Find student row.
  5. Click Pay Now.
  6. Check month-wise due details.
  7. Verify total amount and remaining amount.
  8. Enter amount paid.
  9. Select payment mode and fill fee date and reference number.
  10. Click Submit.

2.9 Full, Partial, and Pending Status

Status Meaning
Paid All selected dues are cleared
Partial Some amount is paid, some due still remains
Pending No payment or full amount still due

2.10 Discount Request

If fee concession workflow is enabled, use discount request option only as per school approval policy. Do not manually reduce fee without approval.

2.11 Payments History

Use Payments button to review previous fee receipts and payment history before collecting new balance fee.

2.12 Daily Fee Counter Workflow

  1. Select active session and working month.
  2. Filter class and section.
  3. Review pending and partial students.
  4. Open fee detail using Pay Now.
  5. Collect payment and save.
  6. Use Payments button if old payment verification is needed.

2.13 Common Mistakes to Avoid

  • Do not collect fee without verifying student identity.
  • Do not enter more than payable amount.
  • Do not leave payment mode and reference blank for online or bank payment.
  • Do not save fee under wrong month or wrong class-section filter.
  • Check previous dues before confirming final amount.
